# Proyecto final — pendiente de definición

Esta carpeta reserva el trabajo de IA del proyecto final. No hay un modelo entrenado, resultados de evaluación ni una entrega final acreditada.

| Carpeta | Contenido previsto |
| --- | --- |
| [datos/](datos/) | Diccionarios de datos y preparación de conjuntos reproducibles |
| [ml/](ml/) | Entrenamiento, evaluación y comparación con una regla base |
| [modelos/](modelos/) | Fichas y referencias a modelos; binarios grandes fuera de Git |
| [resultados/](resultados/) | Métricas, gráficas y límites de la evaluación |
| [informe/](informe/) | Fuentes del informe final |

Primer paso: confirmar el enunciado, definir una pregunta evaluable y acordar la procedencia de los datos. Diferenciar siempre datos del simulador, pruebas sintéticas y mediciones físicas. Una regla de ventilación no constituye por sí sola un modelo de IA.

Los datos y modelos locales se pueden guardar en `datos/local/` y `modelos/local/`, ignorados por Git. No subir secretos ni registros privados.
